## Сохранность и бизнес-правила

Проверены авторизация, отклонение browser Origin, валидация, optimistic revision, транзакционный rollback, история завершения и foreign keys. Тесты используют временные базы.

Планы проверены на сохранение состава и порядка, ранжирование автоплана, исключение завершённых и архивных задач и конфликт версий. Для проектов проверены родитель, циклы, наследование архива и объединение потомков.

Focus проверен на start / pause / resume / finish, точное завершение перерыва, восстановление активного состояния, отдельный подсчёт перерывов, исправление завершённой сессии и агрегацию без двойного счёта. Границы дня рассчитываются в timezone пользователя, включая DST.

С разрешения пользователя исходная база была прочитана через SQLite backup API и проверена на отдельной копии. После v1 → v3 прежние строки задач, истории и настроек совпали с исходными, целостность и резервный снимок прошли проверку. Затем обновлённое основное приложение успешно открыло существующие данные.

## Packaged smoke

Скрипт запускает runtime из подписанного `.app` с временной папкой. Он создаёт проект, предмет, задачу и план, закрывает backend при работающем Focus и запускает его заново. Проверяет стабильные ID, восстановление времени, паузу, продолжение, точные итоги статистики, исключение перерыва, запись настройки прозрачности, целостность SQLite, читаемый backup и остановку по EOF родительского pipe.

## Нативный интерфейс

Проверены создание задачи с заранее выбранным предметом, наличие этой задачи в родительском проекте, генерация автоплана, ручная перестановка и сохранение порядка. Завершённая задача отображается в раскрытой нижней группе Today. Кнопка Edit plan одна.

Проверены переключение и сохранение боковой панели, Shift+Cmd+S, редактор Cmd+N, поиск Cmd+K, английский и русский интерфейс, нативные меню, светлые и тёмные темы. Focus был поставлен на паузу, приложение завершено и запущено вновь: сохранённое время не изменилось; продолжение и завершение создали запись истории с правильным итогом.

При визуальных проверках переработаны пропорции, плотность строк и подложки, а отдельная рамка стекла заменена общей геометрией окна. Прозрачность сохраняется в настройках, нулевое значение даёт сплошной фон. При максимальном значении проверено отсутствие тёмных углов. На отдельной тестовой базе проверены узкая панель с иконками, переключение разделов из неё, стрелки назад/вперёд и восстановление выбранной даты.

## Границы проверки

Developer ID, notarization, Gatekeeper на другом Mac, Windows и старые версии macOS не проверены. Системная сеть принудительно не отключалась, но приложение не использует внешние запросы и работает с локальным runtime. Не выполнялись длительный нагрузочный тест, имитация отключения питания и полноценная проверка скринридером. Reduced motion / transparency и high contrast реализованы; системные настройки доступности отдельно не переключались.

## Подготовка публичного репозитория

Добавлены английский README и русский перевод, MIT, gitignore, правила окончаний строк и workflow сборки macOS arm64 / Windows x64 с read-only правами. Workflow только сохраняет артефакты и не публикует релизы.

После изменений упаковки локально прошли 18 frontend-тестов, TypeScript/Vite, rustfmt, release-сборка macOS, вложенная ad-hoc подпись и smoke через настоящий C-launcher с временной базой. Приложение занимает 166,48 МБ. Результаты помещаются в `release.noindex/`, установленная пользовательская Forma не заменялась.

Windows: добавлены отдельный непрозрачный window config, NSIS для текущего пользователя, PowerShell-подготовка runtime и Unicode launcher с Job Object, а также платформенные подсказки Ctrl. Поля конфигурации проверены по локальной схеме Tauri. Компиляция Windows, установка и ручная проверка UI пока не выполнялись. Первый запуск GitHub Actions ещё впереди.

## Первый запуск GitHub Actions

На коммите `502b259` macOS arm64 прошла полный workflow, включая упаковку и smoke. В Windows успешно прошли frontend-тесты и форматирование; Java сообщил 23 успешные проверки и две ошибки `executionError` при завершении интеграционных классов (`JUnitException` → `IOException`). Полного stack trace в первом логе не было.

Локально подготовлено исправление вероятной причины: контексты Spring интеграционных тестов закрываются после класса через `@DirtiesContext(AFTER_CLASS)`, освобождая SQLite до удаления временного каталога. Добавлены полные исключения Gradle и сохранение XML/HTML отчётов при падении CI. После изменения все 23 Java-теста прошли на macOS. Подтверждение исправления на Windows требует следующего запуска CI; пользовательские данные и код приложения не изменены.
