# Forma

Локальный планировщик для учёбы, повседневных дел и учёта времени. Версия **0.2.0**, ранняя тестовая версия.

[English README](README.md) · [Архитектура](docs/architecture.md) · [Проверки](docs/verification.md) · [Подготовка релиза](docs/releasing.md)

## Возможности

- Задачи с приоритетом, необязательным дедлайном и описанием; фильтры активных и выполненных.
- Проекты и подпроекты: например, «Учёба» → отдельные предметы.
- Ручной план на день или предложение по дедлайнам и приоритетам. Состав и порядок можно изменить.
- Календарь дедлайнов и выполненные за день задачи.
- Таймер для задачи, проекта или общей работы, пауза и перерывы. Активная сессия сохраняется после перезапуска.
- История сессий, статистика и календарь активности.
- Английский и русский, 17 тем, компактная боковая панель и история переходов. На macOS — опциональное стекло.

## Установка и статус

**macOS Apple Silicon:** `Forma-macos-arm64.zip` → распаковать → перенести `Forma.app` в «Программы». Сборка проверена локально, занимает около 167 МБ. Подпись ad-hoc, нотариализации Apple пока нет: скачанное приложение может блокироваться Gatekeeper. Минимум в конфигурации — macOS 12, работа на старых версиях отдельно не проверялась. Liquid Glass доступен на macOS 26, ниже используется запасной вариант.

**Windows x64:** подготовлены скрипты NSIS-установщика и сборка в GitHub Actions. Первая сборка на Windows и ручная проверка установки ещё впереди. Java будет внутри приложения; WebView2 при отсутствии скачивается установщиком. Подпись издателя пока не настроена.

Готовые пакеты после публикации будут в Releases репозитория; тестовые — в артефактах успешного запуска Desktop builds в Actions.

## Данные

Аккаунт не нужен, синхронизации и телеметрии нет. SQLite хранится локально, без шифрования:

- macOS: `~/Library/Application Support/app.forma.desktop/`
- Windows: `%APPDATA%\app.forma.desktop\`

Для ручной копии закройте Forma и скопируйте весь каталог данных. Автоматические снимки находятся в `Backups/`, но экрана восстановления пока нет. Запуск исходников использует тот же идентификатор приложения; для экспериментов с хранением используйте отдельного пользователя ОС. Автоматические тесты работают на временных базах.

## Разработка

Нужны Node.js 22, Rust stable, Python 3 и JDK с `jlink`; сборка использует Temurin 25, Gradle Wrapper 9.1 и Java bytecode 21. Для macOS нужны Xcode Command Line Tools; для Windows — Visual Studio 2022 Build Tools с C++, Windows SDK и Developer PowerShell x64. Укажите `JAVA_HOME`.

```sh
npm ci
npm run prepare:backend
npm run desktop:dev
```

```sh
npm test
npm run build
npm run format:check
npm run package:desktop
```

Результаты сборки — в `release.noindex/`, кэши исключены из Git. Сборка не устанавливает обновление поверх рабочего приложения. Подробнее о проверках и ограничениях — в [основном README](README.md).
